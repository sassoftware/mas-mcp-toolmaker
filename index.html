Build Custom MCP Servers for SAS Viya Decisions and Models

info

📢 A Model Context Protocol (MCP) Server Script for your SAS Viya Micro Analytic Service (MAS) modules.

Python package at: https://pypi.org/project/mas-mcp-toolmaker/

The Python package in this repository generates a Model Context Protocol (MCP) server script to execute published SAS Micro Analytic Services (MAS) modules.

SAS Viya applications like SAS Intelligent Decisioning, SAS Model Manager and SAS Visual Machine Learning use MAS as a publishing destination to serve models, decisions and other programming logic through REST APIs.

Why?​

MCP tools can bloat your agents pretty quickly.

You need specialised and relevant tools which you can pick and choose as per need. mas-mcp-toolmaker helps you do this. This package is a convenient way to interface with a SAS Viya environment using Model Context Protocol (MCP).

tip

📢 Read this article to learn more. Also watch this video.

MCP Server Options​

The MCP server is presented as a Python script oriented for two platforms

  1. Standard Input/Output (stdio)
  2. A format customised for SAS Retrieval Agent Manager (RAM).

A Streamable HTTP version is planned.

Prerequisites​

  1. Package requirements: Python 3.12 or later

  2. Access to a licensed SAS Viya environment with SAS Micro Analytic Service (MAS). This is typically a SAS Viya Enterprise or SAS Viya Advanced offering.

    • While this repo is open source, SAS Viya is proprietary software from SAS Institute. Running SAS Viya requires a license and functioning credentials.

  3. The Viya host and an Access token (details in Installation) to connect to the same, set through the following environment variables.

VIYA_HOST = 
VIYA_ACCESS_TOKEN =

A sample .env is also provided.

  1. (Optional) A SAS Retrieval Agent Manager (RAM) deployment if you want to run the RAM flavour of the MCP server script.

Installation​

  1. The simplest way is to pip install this package from pypi.org
pip install mas-mcp-toolmaker

  1. While not mandatory, we recommended standing up a virtual environment before installing this package. A convenient shell script build.sh is provided for this purpose. Refer this repository for a starter build script. Also read this article for more details.

  2. In case you would like to perform a local install,

# After cloning this repository and entering the top-level directory.

pip install -e .
  1. Use a .env file (refer sample.env, create a copy and rename to .env) to set environment variables for the following: (Refer this link for more details on obtaining access tokens: Authentication to SAS Viya: a couple of approaches)
    • VIYA_HOST: A URL pointing to your SAS Viya environment
    • VIYA_ACCESS_TOKEN: An access token which helps you authenticate to SAS Viya

Note: Maintenance utility for VS Code users​

For those who would like to use this repository in Visual Studio Code, the .vscode directory in this repo contains some automated tasks which perform cleanup of old artifacts (previous virtual environment directories, for example) every time you reopen the repository. Remove this directory in case you do not want the automated task to run.

Operations​

Using this package is very simple. At a fundamental level, there are two operations involved.

  1. Generating a list of MAS modules from a SAS Viya environment
from mas_mcp_toolmaker import MASModule

masm = MASModule()

  1. Writing the extracted modules in tool representation to an MCP server script of your chosen flavour.
masm.script_stdio_server("your_server_file.py")

# or, if you wish to write to a Retrieval Agent Manager file 

masm.script_ram_server("your_ram_server_file.py")

Refer the notebook for other functions.
